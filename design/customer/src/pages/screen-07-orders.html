Status toneKeyed off the canonical sets, not individual statuses, so a status added later inherits a sensible colour instead of falling through to grey. Active → brand, delivered → success, cancelled → danger
Status labelNames the actual state ("Order Picked Up"), never the coarse bucket and never the raw database value

Card anatomy40px status plate · name · reference in tabular label · status chip · one clamped line of items · hairline · date, total, reorder
