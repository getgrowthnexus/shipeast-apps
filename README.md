# ShipEast

Courier and bearer service for St. Thomas and Kingston, Jamaica.

- **Customer app** (`customer_app/`, Flutter) — order, track, Shop & Deliver.
- **Driver app** (`driver_app/`, Flutter) — register, go online, deliver, earnings.
- **Admin panel** (`admin_panel/`, web) — run the operation.
- **Backend** — Firebase (`firestore.rules`, `functions/`), project `shipeast-1a1f6`.

APKs are built by GitHub Actions and published under **Releases**
(`customer-latest`, `driver-latest`).
